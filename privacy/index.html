Privacy on the ayon1xw portfolio

Browsing the portfolio

This is a public personal portfolio hosted on GitHub Pages. The site’s own code does not set analytics or advertising cookies, use browser storage to track visitors, or include an analytics tracker. Hosting providers still receive information needed to deliver requests, such as an IP address and request metadata. GitHub’s handling of that information is covered by its privacy statement. This page does not claim that visiting a hosted website produces no server logs.

Fonts and external links

The pages request fonts from Google Fonts and Google’s font delivery servers. Those services receive network requests when your browser loads the fonts. Links to GitHub, Telegram, and the public profiles site take you to separate services with their own privacy practices. The portfolio does not control how those services store or process information. Follow the provider’s privacy policy if you need details about data processed by that service.

Commission requests

Submitting the commission form sends your Telegram username, project description, optional deadline and reference links, and your acknowledgements to a Cloudflare Worker. The Worker validates the request, checks a rate limit using the source IP address, and forwards the submitted details to my private Telegram chat so I can review and reply. The Worker code does not create a submission database or intentionally log submitted content. Cloudflare processes the network request, and the delivered message remains subject to Telegram’s storage and privacy practices.

Questions about submitted information

Do not include credentials, private keys, or unnecessary sensitive information in a request. To ask about information you have submitted, or request its deletion from the messages I can access, contact @ayon1xw on Telegram and identify the request. There is no automatic deletion schedule in the form or Worker code. Requests about data held by GitHub, Cloudflare, Google, or Telegram may also need to be directed to that provider.
