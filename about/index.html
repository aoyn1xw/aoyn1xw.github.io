About ayon1xw

The developer behind the projects

I’m Erdi, a student developer in Germany. I use the name ayon1xw on this portfolio and aoyn1xw on GitHub. This website is my personal developer portfolio: a place to explain what I build, share source repositories, and help people find the right project. I learn by building things I need, fixing small annoyances, and understanding how the pieces work together.

What I build

My work includes desktop tools, small automations, and local-first experiments. ShadowPlay helps me browse finished game clips from my Windows PC and download the original files to my phone over the local network, using a Flutter client. Other projects include a Swift development container, a Python tool for signing iOS IPA files with certificates and provisioning profiles, and an Untis timetable watcher that sends change notifications.

Explore or ask about a project

The public repositories are the place to inspect code, read each project’s setup instructions, and check its current state. These are personal projects; a portfolio entry is not a promise of commercial support or a hosted service. For a question about code, start with the relevant repository. Small programming commissions follow a separate request and review process described on the commissions and terms pages.
