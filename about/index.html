About ayon1xw

The developer behind the projects

I’m Erdi, a student developer and graphic designer in Germany. I go by ayon1xw here and aoyn1xw on GitHub. I like having a project to try things on, whether that’s an app, a container, or a small automation script. This is where I keep the ones I want to share.

What I build

A lot of my projects start with something I want to use myself. Kivo gets game clips from my PC onto my phone. Swift Devcontainer gives me a Linux environment for iOS builds, and IPA Signer puts signing behind a web form and API. I also work on interfaces, graphic design, and visual identities. The project entries explain what’s implemented and where each tool’s limits are.

What I work with

The projects here use C# and .NET, TypeScript and JavaScript, Python, Dart and Flutter, and Swift tooling. Linux, Docker, and GitHub Actions are part of the setup around them. I also experiment with AI agents, automation, and local language models. I’m still a student, and these projects give me somewhere to learn by building.

Explore or ask about a project

The public repositories are the place to inspect code, read each project’s setup instructions, and check its current state. These are personal projects; a portfolio entry is not a promise of commercial support or a hosted service. For a question about code, start with the relevant repository.
