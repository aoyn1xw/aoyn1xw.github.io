About ayon1xw

The developer behind the projects

I’m Erdi, a student developer and graphic designer based in Germany. I use the name ayon1xw on this portfolio and aoyn1xw on GitHub. I build things because I can: sometimes they’re useful, sometimes they’re experiments, and usually both. This website is my personal developer portfolio, built to explain what I work on, share source repositories, and help people find the right project.

What I build

My work spans web, desktop, and mobile applications alongside UI/UX, graphic design, and visual identities. Kivo helps me browse finished game clips from my Windows PC and download the original files to my phone over the local network, using a Flutter client. Other projects include a devcontainer that builds and signs iOS apps on Linux without a Mac, a Node.js server that signs an IPA with my own certificate and provisioning profile, and small AI agent, MCP, and automation experiments.

What I work with

I mostly write C# for Windows and the web, TypeScript and JavaScript for the front end and tooling, Python for automation and AI experiments, Dart for mobile clients, and Swift where an Apple toolchain is needed. Linux, Docker, cloud, self-hosting, GitHub Actions, and local language models fill the gaps. Every technology named here shows up in one of my repositories, or in the build of this site.

Explore or ask about a project

The public repositories are the place to inspect code, read each project’s setup instructions, and check its current state. These are personal projects; a portfolio entry is not a promise of commercial support or a hosted service. For a question about code, start with the relevant repository. Small programming commissions follow a separate request and review process described on the commissions and terms pages.
