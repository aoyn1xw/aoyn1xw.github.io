# Privacy on the ayon1xw portfolio

## Browsing the portfolio

This is a public personal portfolio hosted on GitHub Pages. The site’s own code does not set analytics or advertising cookies, use browser storage to track visitors, or include an analytics tracker. Hosting providers still receive information needed to deliver requests, such as an IP address and request metadata. GitHub’s handling of that information is covered by its privacy statement. This page does not claim that visiting a hosted website produces no server logs.

The homepage may also request public repository data from GitHub’s API. It keeps a copy in session storage and reuses it for up to 15 minutes before trying to refresh it. This cache contains only public repository data and is not used to track visitors.

## Fonts and external links

The pages request fonts from Google Fonts and Google’s font delivery servers. Those services receive network requests when your browser loads the fonts. Links to GitHub, Telegram, and the public profiles site take you to separate services with their own privacy practices. The portfolio does not control how those services store or process information. Follow the provider’s privacy policy if you need details about data processed by that service.

## Past submissions

The public site no longer includes a commission request form. If you previously used it, your Telegram username, project description, optional deadline and reference links, and acknowledgements were sent to a Cloudflare Worker. The Worker validated the request, checked a rate limit using the source IP address, and forwarded the submitted details to my private Telegram chat. The Worker code does not create a submission database or intentionally log submitted content. Cloudflare processed the network request, and delivered messages remain subject to Telegram’s storage and privacy practices.

## Questions about submitted information

Do not send credentials, private keys, or unnecessary sensitive information in a message. To ask about information you have submitted, or request its deletion from the messages I can access, contact @ayon1xw on Telegram and identify the request. There is no automatic deletion schedule in the form or Worker code. Requests about data held by GitHub, Cloudflare, Google, or Telegram may also need to be directed to that provider.
